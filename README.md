
# RAG4LAW

Citation-grounded legal assistant that analyzes case documents and legal corpus to produce evidence-backed answers.

- Built as a hybrid RAG system using Streamlit for the UI, LangChain for orchestration, and FAISS for retrieval, with custom PDF parsing, semantic + structured chunking, query routing (case/legal/both), and LLM-based answer generation grounded in retrieved sources.
